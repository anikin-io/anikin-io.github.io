Политика конфиденциальности

Трекер · действует с 28.10.2026

Что это за приложение

Трекер — личный планировщик дня, которым пользуется только его автор. Приложение работает на личном сервере автора и не является публичным сервисом.

Какие данные Google используются

Трекер запрашивает одно разрешение: https://www.googleapis.com/auth/calendar.app.created. С ним приложение может создать в Google Календаре пользователя собственный календарь «Трекер» и создавать, менять и удалять события только в нём. Другие календари, события, контакты, почта и любые иные данные аккаунта Google приложению недоступны.

Как данные хранятся

На сервере приложения хранятся только токен доступа к Google и идентификатор календаря «Трекер». Содержимое событий берётся из плана самого пользователя. Данные не продаются, не передаются третьим лицам, не используются для рекламы и для обучения моделей.

Использование и передача данных, полученных из API Google, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ и удалить данные

Отозвать доступ можно в любой момент на myaccount.google.com/permissions — после этого токен перестаёт действовать. Календарь «Трекер» можно удалить в настройках Google Календаря.

Privacy policy

Tracker · effective 28 October 2026

About. Tracker is a personal day planner used only by its author. It runs on the author's private server and is not a public service.

Google data. Tracker requests a single scope, https://www.googleapis.com/auth/calendar.app.created. It lets the app create its own secondary calendar named “Трекер” in the user's Google Calendar and create, update and delete events only in that calendar. The app has no access to other calendars, events, contacts, email or any other Google account data.

Storage and sharing. The server stores only the Google access token and the ID of the “Трекер” calendar. Event content comes from the user's own plan. Data is never sold, shared with third parties, used for advertising or used to train models. Tracker's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions. The “Трекер” calendar can be deleted in Google Calendar settings.
